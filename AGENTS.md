# roby.media

Bilingual (RO/EN) marketing site for a Romanian video, photo and marketing agency. Next.js 16 App Router, next-intl, Tailwind 4, Framer Motion, zod, nodemailer. Content lives in JSON/MDX under `content/`. Code comments are in Romanian; keep that. This file is in English.

**Priorities, in order:**
1. Conversion: the quote form, WhatsApp and phone actions must work on every page.
2. Bilingual RO/EN SEO: localized slugs, sitemap, hreflang, JSON-LD and metadata stay intact.
3. Performance: LCP and CLS. Server components by default, client components small.
4. Romanian diacritics (ă â î ș ț) render correctly (Anton display font, `latin-ext` subset).

Use these to break ties.

**Read `docs/NEXT_STEPS.md` at the start of a session:** current status and next task.
**Read `docs/DESIGN.md` before changing UI, colors, type or motion.**

## Map

- `app/[locale]/`: pages. Each language has its own folder names for the same page (`servicii`/`services`, `despre`/`about`, `pachete`/`packages`, `portofoliu`/`portfolio`, `zone-deservite`/`areas-we-serve`, plus legal pages). `[slug]/page.tsx` serves RO city pages (`/filmare-nunta-cluj-napoca`).
- `app/api/contact`: POST handler for the quote form (zod, honeypot, in-memory rate limit, nodemailer). `app/api/og`: dynamic OG image (reads `assets/fonts/`).
- `app/sitemap.ts`, `robots.ts`, `manifest.ts`, `fonts.ts`, `globals.css`: SEO files, fonts, Tailwind entry.
- `components/views/*`: page bodies, one per page type. `sections/`, `layout/`, `ui/`: shared pieces. `layout/conversion-bar.tsx` is the mobile call/WhatsApp/quote bar. `ui/json-ld.tsx` renders structured data.
- `lib/routes.ts`: the only source of URLs. `lib/seo.ts`: canonical, hreflang, metadata, `SITE_URL`. `lib/content/`: zod schemas and loaders. `lib/contact-schema.ts`: form schema shared by client and server. `lib/links.ts`, `lib/analytics.ts`: contact links and consent-gated tracking.
- `i18n/`: `routing.ts` (locales, `as-needed` prefix) and `request.ts`. `messages/{ro,en}.json`: UI strings only.
- `proxy.ts`: replaces `middleware.ts` in Next 16. Redirects `/ro/...` to `/...` (308), then runs next-intl.
- `content/`: all site text and data; see `content/README.md` for each file. `scripts/`: content validation, city skeleton generator, standalone prep.
- Deploy: `netlify.toml` (OpenNext plugin), `Dockerfile` + `docker-compose.yml`, `ecosystem.config.cjs` (PM2). `next.config.ts` sets `output: "standalone"` and `outputFileTracingIncludes` for runtime-read files.

## Rules

- Routes: Romanian at the root, English under `/en`, `localePrefix: "as-needed"`. Slugs differ per language. Build links only with helpers from `lib/routes.ts`; never hardcode a path or a locale prefix. A new page needs entries in `STATIC_PATHS`, a folder per language, the sitemap and hreflang.
- hreflang is generated by `lib/seo.ts` (next-intl `alternateLinks` is off). `ro`, `en` and `x-default` (to RO) on every page, with matching canonicals.
- City pages are RO only. A city with `"ready": false` in `content/cities.json` must stay `noindex` and out of the sitemap. Do not flip it without real local content.
- Do not hand-edit generated or content-driven URLs. Add content in `content/`, then run `npm run validate:content`.
- Romanian diacritics use comma-below (ș ț), never cedilla (ş ţ); the validator rejects cedilla. Check any new font or subset renders them.
- Anything under `content/` or `assets/` that a route handler reads at runtime must be listed in `outputFileTracingIncludes` in `next.config.ts`, or it is missing in the standalone build.
- Do not remove or break the quote form, the WhatsApp link, the `tel:` link or the mobile conversion bar when editing a layout or view.
- Tracking (GA4, Meta, TikTok) loads only after cookie consent. Keep it that way.
- In `ecosystem.config.cjs`, PM2 must keep `HOSTNAME: "localhost"`. `127.0.0.1` breaks next-intl rewrites into a redirect loop.
- Mail: `/api/contact` reads `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM`, `MAIL_TO`. Without SMTP it logs in dev and returns 500 in production. Other env vars: `NEXT_PUBLIC_SITE_URL`, `NEXT_PUBLIC_GA4_ID`, `NEXT_PUBLIC_META_PIXEL_ID`, `NEXT_PUBLIC_TIKTOK_PIXEL_ID`, `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`. `NEXT_PUBLIC_*` are baked in at build time. Names are in `.env.example`; never write values into the repo or into replies.
- Framer Motion and other client libraries belong in small leaf components. Keep pages and views as server components.

## Before calling it done

- Run the narrowest check that covers the change. Content edits: `npm run validate:content`. Code: `npm run lint`, then `npm run build` for shared or risky code.
- UI changes: look at the page in a browser in both RO and EN, mobile and desktop, and confirm the form, WhatsApp and call actions still work.
- SEO-affecting changes: check the page's canonical, hreflang, JSON-LD and sitemap entry for both languages.
- Update `docs/NEXT_STEPS.md` if the status or next task changed.
